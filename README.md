# Galeria de Arte

Este projeto consiste em uma aplicação web para busca de obras de arte utilizando uma API pública. A aplicação permite que o usuário pesquise obras e visualize informações básicas sobre elas.

## Desenvolvido por

Paloma Francine Torrijos  
Ana Caroline Campopiano  

## Objetivo

O objetivo do trabalho é aplicar conceitos de desenvolvimento web utilizando HTML, CSS e JavaScript, além de realizar o consumo de dados de uma API externa.

## Funcionalidades

- Buscar obras de arte por nome ou artista  
- Exibir título, artista e data da obra  
- Excluir itens da lista  
- Armazenar dados no navegador com LocalStorage  

## Tecnologias utilizadas

- HTML  
- CSS  
- JavaScript  
- API do Art Institute of Chicago  

## Como executar

1. Baixar ou clonar o repositório  
2. Abrir o arquivo index.html no navegador  

## Observação

Este projeto foi desenvolvido para fins acadêmicos.
